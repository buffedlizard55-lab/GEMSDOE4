## Changes implemented in this review

1. **Direct inference now uses the same fail-loud GeoTIFF writer as blending.** The prior fix protected
   `scripts/blend_submission.py`, but `src/inference.py` still forced `TILED=YES` onto the striped sample
   profile. `clean_profile()` now removes stale block geometry and `write_submission()` reads the file back,
   checks the grid, dtype, tiled block dimensions, finite pixels and non-zero mass before success is reported.
2. **Workflow failures can no longer be hidden by a filtering subshell.** Training and inference pipelines
   now use `set -euo pipefail` without `(... || true)` in the Python pipeline. The ensemble blend refuses to
   proceed when any matrix fold fails. Failure evidence remains collectable, but a broken run cannot be
   presented as a valid submission.
3. **Optional USGS 3DEP DEM features are now explicit and symmetric.** A local DEM mosaic is reprojected
   to the exact feature grid with average resampling; five derivatives are appended consistently during
   both training and inference. The default GPU config now leaves this option off until
   `external_dem_path` is supplied, rather than silently using a guessed feature channel.
4. **Lightweight test imports work without the heavy segmentation stack.** `segmentation-models-pytorch`
   is imported only when a model is constructed, so metric, data and format tests can run without SMP.
5. **Rules-evidence test handles reports without a committed PDF text extract.** `verify-sources.yml` may
   publish quote verdicts without the optional extracted text; the test now skips that optional check
   cleanly instead of treating the repository root as a file.
