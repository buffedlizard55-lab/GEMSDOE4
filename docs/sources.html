Irregularity, recorded not hidden. Runner-side HTTP verification (scripts/verify_links.py) intermittently times out on sciencebase.gov DOI redirects - exactly one DOI per run, and it is a different DOI each run (P9Z6SA1Z, then P9MQRCBY; P9TWT2LU resolved). Both were resolved on the same day by the platform fetcher, so this is ScienceBase latency or bot-throttling, not a dead link. Recorded here rather than silently retried.
Why this matters for the leaderboard. The scored faults are the ones missing from the INGENIOUS catalogue, and the detrended-elevation and geophysics grids are that project's own fault-emphasising products: free, public-domain, officially released, and already inside the study area. They are the lowest-risk additional inputs to test against the negative-sampling baseline (see Results).

Calling either one "broken" would itself be an inaccuracy, so they are reported separately.
