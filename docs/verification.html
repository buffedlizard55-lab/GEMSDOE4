The competition scores a public split of the expert-labelled new faults on a public leaderboard while the prize round itself is scored privately. This repository is not on it. This repository has never been scored by the competition. Producing a submission file is automated (train -> blend -> validate -> committed GeoTIFF), but uploading one needs the entrant's account: the data tab and the submission form both sit behind the login, and the competition rules require the entrant to be a US citizen or permanent resident. Until a human uploads submission.tif (three chances a week), every number in this repository is a local proxy - catalogue DTI, proxy-catalogue DTI, held-out-crop DTI - and none of them is the leaderboard.
How to read the local numbers on this site against that bar: the catalogue DTI (about 0.19 on held-out crops) is measured on faults the model trained on, so it is an upper bound on plumbing, not on skill; the proxy-catalogue DTI is measured on mapped faults the training labels do not contain, and is the honest local monitor. Neither is the leaderboard, and the gap between them is the subject of the metric page.

What could not be reached, and what it costs

  • the data download page and the submission form — both redirect to /accounts/login/ - no credentials exist in this environment
    Impact: submission files are produced and validated here but must be uploaded by the entrant
  • the example PNGs behind the official metric worked example — drivendata-public-assets.s3.amazonaws.com is not on the sandbox allowlist and fetch_page returns page text, not pixel data
    Impact: src/metrics.py --self-test check [4] cannot reconstruct the example raster exactly; the arithmetic check [3] against the published components is exact
  • the Dropbox mirrors of the competition rasters — www.dropbox.com is refused from this sandbox's bash (the GitHub Actions runners download them successfully and record the sha256 in data/evidence/)
    Impact: the official files cannot be pulled into this sandbox; all training, inference and scoring in this repository therefore happens on the runners, and the numbers below come from the evidence those runs committed
