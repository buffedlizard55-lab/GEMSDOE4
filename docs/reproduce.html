Reproduce

Every command needed to rebuild the data, the model and this site.

Get the data

Preferred (2026-09-17): reassemble from the committed git bridge — no login, no network:

git pull                                   # data/bridge/ holds sha256-pinned parts
python scripts/assemble_data_bridge.py     # re-verifies every part, places canonical names
python scripts/prepare_data.py             # validates CRS, resolution, bounds, bands

Every part's sha256 is pinned to the independent inventory (data/evidence/inventory.json); the assembler refuses to write anything on a mismatch (regression-tested in tests/test_data_bridge.py).

Alternatively, the competition files require a DrivenData login. With an account:

bash scripts/download_competition_data.sh   # bridge first, else Dropbox mirrors from the data tab
python scripts/prepare_data.py              # validates CRS, resolution, bounds, bands

prepare_data.py exits non-zero on any mismatch, so a bad download is caught before hours of training.

Train and build a submission

# GPU box, full capacity
python -m src.train     --config configs/config.yaml
python -m src.inference --config configs/config.yaml --out submission.tif
python scripts/validate_submission.py --pred submission.tif --sample data/sample_submission.tif

# CPU, proves the pipeline on the real rasters
python -m src.train --config configs/config_ci_smoke.yaml

# CPU, ensemble: one fold (repeat per fold), raw map, then blend+shape across folds
python -m src.train --config configs/config_ci_ensemble.yaml --override training.mc_id=0
python -m src.inference --config configs/config_ci_ensemble.yaml --raw --out outputs/prob_raw.tif
python scripts/blend_submission.py --folds outputs_f0 outputs_f1 ... --out submission.tif

# In-sandbox, against the committed real-data fixture (no download needed)
python -m src.fixture                                    # verify the fixture
python -m src.train --config configs/config_fixture.yaml

Automation

GitHub Actions workflows do the work that needs open network access:

  • Place competition data (git bridge) — downloads the three official rasters from the data-tab Dropbox mirrors, verifies each sha256 against the pinned inventory, runs the pre-flight validation and commits them as ≤ 90 MiB parts so the egress-restricted sandbox can receive them over git (data/bridge/).
  • Fetch competition data — downloads the files, measures them, OCRs the DEM PDF, resolves tiles against the USGS bucket, verifies every link, builds the dev fixture, and commits the evidence JSON back to the branch.
  • Train and build submission — single-job smoke: train → inference → validation → scoring, uploads submission.tif as an artifact.
  • Proxy catalogue (independent faults) → evaluate — fetches USGS SGMC structure polylines, rasterises them on the competition grid, splits them into "already in the labels" and "absent from the labels", scores the committed submission against the absent part with the official metric, and sweeps the shaping policy on it. This is the only local measurement on a population that resembles the scored one, and its evidence (including the blanket-ones baseline that beats our current emission) is committed under data/evidence/proxy/.
  • Verify official rules quotes — re-downloads the official rules PDF, re-extracts every quoted sentence verbatim, and commits the report; Verification records what each external claim rests on.
  • Train MC ensemble (parallel folds) + blend — six fold jobs train one MC split each (--override training.mc_id=F) and blend the raw probability maps in a final job with one shaping pass calibrated on the pooled held-out DTI. Reports and the shaped submission are committed back to the branch under data/evidence/runs/<run_id>/.

Submitting

Upload submission.tif via the Submit tab at https://www.drivendata.org/competitions/306/competition-doe-gems/. Requirements checked by scripts/validate_submission.py: single band, float32, values in [0,1], EPSG:32611, 100 m, identical grid and transform to the provided template (spec). Note the competition requires choosing a single submission for scoring in both rounds before the deadline.
