⚠ Irregularity: the sample submission is a copy of the labels

The problem page states: "A sample submission that predicts total fault absence is provided for your reference." (source)

Measured instead: example_submission.tif contains 60,988 positive pixels — identical to existing_faults.tif (60,988). Binary content identical across all 5,167,373 commonly-valid pixels: True.

Why it matters: anyone using the "sample" as a zero-filled template gets a file pre-populated with the known faults. Practical impact: none for us — we write submissions from the sample's georeferencing only and fill values from the model. Flagged for organiser review.

1 m DEM tile list

The competition provides 1m_DEM_links.csv; the public mirror is a PDF. Measured: that PDF has no text layer — pypdf, pdftotext and pdfplumber each return 0 URLs. It is a scan.

OCR (tesseract, 300 DPI)722 (project, tile) pairs parsed
Confirmed against the USGS bucket716 unique tiles
Unmatched (flagged)3
Why no URL here was typed by a machine-guess. OCR of this scan corrupts characters — 2020 reads as 202@, underscores become spaces, QL1/QLi are ambiguous. Rather than repair characters and hope, the parser extracts only the structure (project name + x##y### tile id) and then resolves every URL against a live ListObjectsV2 enumeration of the official USGS 3DEP bucket. Emitted URLs are verbatim bucket keys. Anything unmatched is listed as an irregularity, never guessed.

Full list with provenance: data/dem_links.json

Working around a restricted network

The development sandbox can reach only github.com and pypi.org; Dropbox, S3, the Azure host serving Actions artifacts, and DrivenData itself are all blocked. Data is therefore fetched by a GitHub Actions runner, which has open egress, and results return as commits. A 890.0 MB raw feature cube compresses to:

EncodingSize
float32_zstd22_pred3238.0 MB
float32_deflate9_pred3240.2 MB
int16_zstd22_pred2101.1 MB

Still too large to commit, so a 512×512 window of the real rasters is committed instead (data/fixture/, ~5 MB, int16-quantised with measured round-trip error 1.6×10⁻⁵ of each band's range). That fixture is what lets the pipeline be developed and tested in-sandbox against true band semantics.
